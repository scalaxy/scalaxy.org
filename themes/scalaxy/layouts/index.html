Overview

What is Scalaxy

Scalaxy is a graph and key/value database that fits in one binary. The database serves its own web console and includes an openCypher engine, so a deployment is a single file plus a data directory: no server stack, no separate frontend, nothing extra to install.

Topologies

Same code, three ways to run it

The binary is identical in every setup; only the environment variables change. Run one node on a laptop, a replicated cluster on a few machines, or a StatefulSet in Kubernetes.

Single node

One node, a durable log, and a web console. Fine for development, small services, and edge devices.

Topologies →

Cluster

Keys shard across N nodes and writes replicate synchronously, so reads and writes keep working when a node goes down.

Topologies →

Kubernetes

A StatefulSet with PVCs, probes, and peer discovery over headless DNS. Add pods to grow the ring.
