Overview

What is Scalaxy

Scalaxy is a distributed key/value database engineered to be easy to run: a single binary, an embedded operations console, and container-first deployment.

Independent project since 2014 — associated with scalaxy.org, not affiliated with, sponsored by, or operated by Scalaxy B.V. or scalaxy.com.

Topologies

One engine, many shapes

From a single embedded node on a laptop to a replicated cluster behind Kubernetes, Scalaxy adapts to the topology you need.

Single node

An embedded durable store with a web console. Perfect for development, edge, and small workloads.

Topologies →

Cluster

Consistent-hash sharding across N nodes with synchronous replication — reads and writes survive node loss.

Topologies →

Kubernetes

A StatefulSet with PVCs, probes, and peer discovery via headless DNS. Scale the ring by adding pods.
